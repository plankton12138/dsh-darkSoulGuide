# README 截图清单

README 里引用了三张图，文件名已固定。把文件放到本目录即可生效，不用改任何 markdown。

| 文件名 | 拍什么 | 建议构图 |
|---|---|---|
| `pill.png` | 输入框左侧的进度药丸，**展开状态** | 裁掉页面其余部分，只留输入框那一带；要能看清等级、当前位置、六条进度轴和快捷提问芯片 |
| `panel.png` | 左侧栏「黑魂3 进度」页 | 保留侧栏宽度，能看到区域连通图、篝火完成度、下一步建议 |
| `ask.png` | 对话里问一次「我接下来该去哪」及它的回答 | 保留用户那一句和回答的开头；回答里带真实数字才有说服力 |

## 怎么拍

1. 先确认已重启 DSH，侧栏能看到「黑魂3 进度」
2. 新建对话，选「黑魂3 攻略」预设
3. 把进度药丸点开、侧栏页切到进度图
4. `Win + Shift + S` 截图 → 存成本目录下的对应文件名

## 注意

- **不要出现 Steam 账号 ID、真实姓名或存档路径**。角色名和等级是游戏内容，可以留下；`%APPDATA%\DarkSoulsIII\<SteamID>\` 这类路径不要进图。
- 宽度 1200–1600px 之间最稳，太窄在 GitHub 上会糊。
- 截图里如果有别的会话标题、聊天列表或系统信息，裁掉。
