# 黑魂攻略助手 · dsh-darksouls-guide

一个能**读你存档**的《黑暗之魂3》攻略助手。它知道你打到哪、杀了谁、还差哪些篝火和戒指，然后回答「接下来该干什么」。

不需要你复述进度，也不要求你打开攻略站对照着看——它读的是你机器上那个真实的存档文件。

> **项目持续更新中。** 当前版本 **0.11.4**。正在做的方向：NPC 任务线、区域内导航、更完整的知识库。见 [更新计划](#更新计划)。

## 它能帮你做什么

| 你想知道 | 它会告诉你 |
|---|---|
| 我是什么流派、该怎么加点 | 九项属性、当前装备、还差哪些质变 |
| 我打到哪了、玩了多久 | 等级、当前所在、游戏时长、Boss 进度 |
| 还有哪些 Boss 没打 | 24 个主线与 DLC 主要 Boss，逐个点名 |
| 我漏了哪些篝火 | 按区域分组，说清哪一块没点亮 |
| 还差哪些戒指、法术、誓约 | 按背包实际持有判定，按家族计数 |
| 现在能立刻拿到什么 | 已击败却没兑换的 Boss 灵魂、教团还差几枚 |
| 成就还差哪些 | 读 Steam 成就，附未解锁清单 |
| 哪些结局还差 | 三个有成就的能查；**夺火无法核验，它不会替你瞎猜** |
| 这个物品在哪 | 三段式指引：你现在能不能拿 / 从哪个篝火怎么走 / 有什么坑 |
| 接下来按什么顺序走 | 路线规划，已区分传送与步行 |

**进度按缺口报，不按百分比报。** 「戒指 37/71」能推出还差 34 枚，「52%」推不出来。戒指按**家族**计数，+1、+2、+3 不算新戒指——否则你的收集列表会虚高一倍。

## 开始使用

1. **安装插件**，重启 DSH（见 [安装](#安装)）
2. **新建对话，选「黑魂3 攻略」预设** ——这一步很关键
3. 直接问，比如「我现在该去哪儿」「还差哪些篝火」

> 工具和存档上下文只在「黑魂3 攻略」预设里生效。不选预设的话，助手不会读你的存档，回答就只能靠猜。侧栏的进度页不受此限制，随时都能看。

## 界面

**输入框左侧的进度药丸。** 一眼看到等级和当前位置；点开是六条进度轴和快捷提问，点一下芯片，问题就填进输入框，你看过再发送。没有存档时它不会消失，而是变成一个灰点，点开告诉你缺什么。

**左侧栏的进度图。** 19 个区域的连通关系、每个区域的篝火完成度、以及「下一步」建议。这一页不需要选预设，随时可看。

**在对话里提问。** 回答会引用存档里的真实数字，而不是泛泛的攻略。

**页面上每个数字都能点。** 快捷提问芯片、地图上没点亮的区域、成就里缺失的具体物品——点一下，问题进输入框，你可以先改再发。

## 第一次用会遇到什么

**没有存档**时，面板会直接告诉你它去哪找了、你该做什么，而不是只说一句「读取失败」：

```
读不到存档：没有找到《黑暗之魂3》存档
默认查找 %APPDATA%\DarkSoulsIII\*\DS30000.sl2 —— 请确认游戏至少创建过一个角色并保存过。
```

**缺 Python 或依赖**时，侧栏会列出三项检查——Python 3、`cryptography`、存档路径——出问题的那项标黄，旁边是可直接复制的修复命令。修好点「重新读取」，不用等。

刚在游戏里存过档？点一下「重新读取」就行，不用重启。

## 它不会做什么

- **不写存档。** 只读。写回要重算校验，在线模式还有封禁风险，这个项目不做。
- **不联网拉攻略。** 游戏知识走本地数据，不会把你的存档或问题发到第三方攻略站。
- **还没有区域内导航。** 「缺哪一块」能答，「从哪个门进去」还答不了。
- **不猜。** 存档里看不出来的，它会说看不出来。存档读不到成就，所以成就以 Steam 为准；没装 Steam 时这部分明确降级为「读不出」，不会编。

## 安装

当前版本 `0.11.4`，属于 **0.x 开发者预览版**：能用，但接口和界面还会变。

**环境要求**

| 前置 | 要求 | 不满足时你会看到 |
|---|---|---|
| 系统与存档 | Windows + PC 版《黑暗之魂3》，且创建过角色并保存过 | 面板显示「读不到存档：没有找到《黑暗之魂3》存档」，并列出默认查找路径 `%APPDATA%\DarkSoulsIII\*\DS30000.sl2` |
| Python | Python 3，且 `python` / `python3` / `py` 任一个在 PATH 上 | 面板显示「没有找到可用的 Python 解释器」，检查表里 Python 3 一项标黄，并给出已尝试过的解释器名 |
| cryptography | `pip install cryptography` | 面板显示「解析器缺少 Python 依赖」，修复命令就是 `pip install cryptography` |
| DSH | 0.2.x，声明为 `engines.dsh: >=0.2.1-rc.1 <0.3.0` | 市场会按这个范围标记不兼容，安装或启用会被拦住；强行装上去工具与面板都不会加载 |

**从 npm 安装**

在 Harness 会话里让 agent 执行：

```
plugin_manager action=install_bundle target=dsh-darksouls-guide@0.11.4
```

或用 DSH CLI：

```powershell
npx @deepseek-ai/dsh plugin add dsh-darksouls-guide
```

**从本目录安装（开发用）**

```powershell
plugin_manager install_bundle target=<本目录绝对路径>
```

装好后重启 DSH，新建对话时选「黑魂3 攻略」预设。

## 常见问题

**进度显示的是新周目，不是我之前的角色？**
存档在开 NG+ 后会把 Boss 与进度旗标重置，这是游戏行为，不是读取错误。Steam 成就跨周目保留，所以「拿过哪些结局」仍然准确。

**有多周目或多个角色怎么办？**
目前默认读取存档里的第一个角色。多角色切换还在做。

**为什么说「夺火」无法核验？**
它没有成就、存档也不留任何标记。这个项目宁可说「不知道」，也不替你断言拿过或没拿过。

## 更新计划

这个项目在持续更新，按优先级：

1. **NPC 任务线** —— 现在能读任务旗标，但标签覆盖不全，所以还没开放。需要多周目存档对照来标定。
2. **区域内导航** —— 从「缺哪块」到「从哪个门进去」。
3. **知识库** —— 更完整的物品、地点与前置条件。
4. **多角色切换**。

已知限制会同步写进 [docs/blueprint.md](docs/blueprint.md)，包括还没解决的和明确不做的。
